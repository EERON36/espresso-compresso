# Espresso Compresso v1.0.0

The first portable Windows release of Espresso Compresso.

## Download and start

1. Download `Espresso-Compresso-Windows-x64.zip` below.
2. Extract the entire ZIP.
3. Open the extracted folder and double-click `Espresso Compresso.exe`.

Python and HandBrake do not need to be installed. The required runtime and video tools are included.

For a first run, keep **Smaller** selected, keep the originals, and test three files. **Fast** is optional and requires a compatible NVIDIA RTX GPU and driver.

Windows may show a SmartScreen warning because this private build is not code-signed. Only continue if the file came from this private repository or directly from someone you trust.

The two source archives are included as separate release assets to accompany the bundled HandBrakeCLI and FFmpeg builds.
